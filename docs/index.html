Compile-Time Memory Safety
for C and C++

MemSentinel is a pure native GCC/G++ plugin that stops compilation immediately when memory bugs are detected. Zero wrappers, zero scripts. Standard raw pointers and pointer arithmetic fully supported.

Enforced Safety Guarantees

MemSentinel performs intra-procedural GIMPLE SSA typestate analysis directly inside GCC.

🛑

Double Free Rejection

Instantly aborts compilation if free() or delete is invoked on a pointer already marked as deallocated along any control-flow path.

⚠️

Use-After-Free (UAF)

Dereferencing (*ptr), array indexing (ptr[i]), or member access (ptr->field) on freed memory causes an immediate fatal compile error.

📐

Altered Base Free Guard

Catches pointer arithmetic before deallocation (e.g., p++; free(p);). Rejects attempts to deallocate interior offsets instead of original base addresses.

💧

Memory Leak Detection

Identifies dynamically allocated heap memory whose aliases are lost or that exits function scope without being freed or escaped to caller.

🚀

Unrestricted C/C++

Zero language restrictions. Use raw pointers, custom allocators, dynamic structures, and pointer arithmetic with complete idiomatic freedom.

🛡️

Runtime Guardrails

Secondary runtime safety net (libmemsentinel_rt) catches dynamic edge cases, logging detailed forensics into memcheck_runtime.log.

Architecture Pipeline

How MemSentinel operates inside the compiler pass pipeline.

1. Source Ingestion

Target C/C++ with unrestricted raw pointers and malloc/new.

➔

2. SSA Typestate Pass

Intra-procedural dataflow tracks allocation base & offset delta.

➔

3. Invariant Verification

Enforces pointer validity before every deallocation and read.

➔

4. Outcome

error_at terminates build OR binary safely emitted.

Detection In Action

See how the compiler reports memory unsafety before executable code is produced.

// example.c
#include <stdlib.h>

void faulty_routine() {
    char* buf = (char*)malloc(32);
    buf += 4;  // Pointer shifted by +4 bytes!
    free(buf); // Rejection: Attempt to free interior pointer!
}

/* Output from GCC: */
example.c:7:5: error: [MEMSENTINEL] Attempt to free altered/interior pointer 'buf'.
    7 |     free(buf);
      |     ^~~~~~~~~
example.c:5:17: note: Original allocation base was created here (size: 32 bytes):
    5 |     char* buf = (char*)malloc(32);
example.c:6:5: note: Pointer address was shifted by +4 bytes prior to deallocation.
compilation terminated due to memory safety violations.

Installation & Integration

Pure plugin loading without wrappers. Select your environment:

# 1. Copy plugin to your MinGW GCC plugin directory
Copy-Item "memsentinel.dll" "$((gcc -print-file-name=plugin).Trim())\"

# 2. Drop the specs file into GCC's installation directory for auto-loading
Copy-Item "memsentinel.specs" "$((gcc -print-file-name=specs).Trim())\specs"

# Done! Every gcc/g++ call automatically runs MemSentinel.
# To disable for specific builds:
gcc -fplugin-arg-memsentinel-disable main.c -o main.exe
# 1. Install to GCC plugin directory
sudo cp memsentinel.so $(gcc -print-file-name=plugin)/

# 2. Register specs for default auto-load
sudo cp memsentinel.specs $(dirname $(gcc -print-libgcc-file-name))/specs

# 3. Compile as normal
gcc -O2 main.c -o main
# With Homebrew GCC (gcc-13 / gcc-14)
sudo cp memsentinel.dylib $(gcc-14 -print-file-name=plugin)/
gcc-14 -fplugin=memsentinel main.c -o main
